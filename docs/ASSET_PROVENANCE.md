# Raster asset provenance

This inventory records what the project currently knows about shipping raster assets. It is not a licence grant. Confirm ownership or permission before public deployment.

## Menu illustrations

- **Files:** `public/images/menu/*.jpg`
- **Origin:** AI-generated illustrative samples created for this student project.
- **Use:** Sample dish imagery only. The images are not photographs of the actual APU meals or proof that a kitchen serves the pictured item.
- **In-product credit:** Seeded menu records use `AI-generated illustrative sample; actual kitchen item may differ.` as `photoCredit`.
- **Restrictions:** Keep the menu marked **Sample** until the operator reviews and replaces it. Do not present these images as vendor-supplied photography.

## Cafeteria photographs

- **Files:** `public/images/cafeterias/*.jpg`
- **Origin:** Restaurant/cafeteria photographs supplied to the project team for development.
- **Use:** Retained as possible future kitchen banners; not used as dish photographs.
- **Permission status:** Repository documentation does not establish vendor approval or a public redistribution licence. Obtain and record permission before public deployment.

## Application icons

- **Files:** `public/icon-192.png`, `public/icon-512.png`
- **Origin:** Existing BreakBite application-logo assets already present in the repository before this homepage redesign.
- **Permission status:** No separate source record is currently stored. The project owner should confirm authorship or licence before public redistribution.

## Homepage redesign

The Spectral Lunch Rail redesign added no new raster assets. It reuses the existing BreakBite logo and the menu illustrations above. CSS layout, timing markers and interface decoration are code-authored.

## Operator uploads

Runtime kitchen uploads are stored outside the source catalogue. The operator flow requires a source/credit and explicit confirmation that the uploader owns the image or has permission. That acknowledgement is evidence supplied by the operator, not independent verification by BreakBite.
